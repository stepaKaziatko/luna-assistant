# Руководство пользователя Luna

Luna живёт в вырезе MacBook (на мониторе без выреза — в полоске у верхнего края) и присматривает за сессиями ИИ-агентов: Claude Code, Codex, Gemini CLI, Cursor, Copilot CLI, OpenCode, Amp, Hermes и других. Из острова можно разрешить или отклонить запрос агента, ответить на его вопрос, перейти к его окну, поговорить с моделью, бросить файл, следить за GitHub, Vercel, Stripe и другими сервисами — не отрываясь от работы. В острове — маленький персонаж, который дышит, моргает и следит за курсором.

Здесь — как поставить Luna, подключить агентов и пользоваться островом. О сборке из исходников, устройстве проекта и выпуске — в [README](../README.md).

## Что умеет

- **Страница «Агенты»** — она же домашняя: по плитке на каждую сессию агента с аватаром, проектом, приложением, где идёт сессия, и последними шагами. Кто ждёт вашего разрешения или ответа — первый и горит оранжевым, закончивший ход — зелёным, ошибка — красным.
- **Страница агента:** одна сессия подробно, последние 20 шагов. Если агент ждёт вас — здесь же его вопрос с вариантами ответа или запрос разрешения с кнопками Allow / Deny / Always. Ничего не разрешается без вашего клика.
- **«Перейти к агенту»** открывает окно, где идёт сессия: в VS Code и родственных редакторах — папку проекта и вкладку Claude Code, в Terminal и iTerm2 — именно ту вкладку, в других терминалах — само приложение, а если неизвестно, где запущен агент, — папку проекта в Finder.
- **Агенты на челке.** Свёрнутый остров показывает маленькую Luna на каждую сессию, где есть новости. Задержите курсор на челке — вырастет блок с самыми срочными агентами; приложение, в котором вы работаете, остаётся активным.
- **Сессии в «таблетках»:** что агент читает, правит и запускает, шаг за шагом; правки файлов с `+N −M`, по клику — полный diff.
- **«Активные вкладки»** — отдельная страница с рабочим местом, ИИ для чата, сервисами и планом Claude и Codex. Когда подключён GitHub, в шапке появляется своя вкладка: мои PR с CI и ревью, что ждёт вашего ревью, CI основной ветки.
- **Управление с клавиатуры:** `⌃⌥S` открывает «Агенты», `⌃⌥P` — «Активные вкладки», дальше стрелки, `↩`, `⌫`, `⎋`; `⌘⎋` сворачивает раскрытую шторку из любого приложения. Подробно — в разделе [Хоткеи](#хоткеи).
- **Чат** с Claude, Gemini, OpenAI или локальной моделью (Ollama, LM Studio) по своему ключу — или по вашей подписке через установленный Claude Code, без ключа API. Диктовка в чат; лимиты плана Claude и Codex в шапке.
- **Проекты:** привязанные папки с вашего Mac; у агентов видно, в каком проекте они работают. Подробно — в разделе [Проекты](#проекты).
- **Агент в проекте:** задача со страницы вопроса с выбранным проектом запускает в фоне агента Claude Code в папке проекта — его плитка на «Агентах», разрешения кнопками в острове, ответ и продолжение на странице агента. Подробно — в разделе [Агент в проекте](#агент-в-проекте).
- **Интеграции:** GitHub, Vercel, Stripe, Resend, n8n, Notion, Cal.com, Apple Music, Spotify, Apple Mail, курсы криптовалют.
- **Файл на остров** — персонаж «проглатывает» его, дальше вопрос по файлу или письмо.
- **«OK Luna»** — голосовое управление: речь распознаётся на Mac, в Anthropic уходит только текст.
- **Еженедельный отчёт** по понедельникам: время, сессии, файлы, строки, команды.

Интерфейс на десяти языках, без телеметрии, ключи хранятся в Связке ключей (Keychain).

## Требования к системе

- **macOS 15 или новее.** На более старой системе скрипт установки откажет.
- **Apple Silicon или Intel** — одно универсальное приложение (arm64 и x86_64 в одном бандле).
- **Экран.** На MacBook с вырезом остров встаёт в вырез; на Mac без выреза и на внешних мониторах — полоской у верхнего края. На каком экране показывать остров, выбирается в Настройки → Основные (Display): экран с вырезом, главный экран, экран под курсором или конкретный монитор.
- **Для наблюдения за агентами** — сам CLI агента (Claude Code, Codex, Gemini CLI…) и хуки Luna в его настройках (см. [Подключение агентов](#подключение-агентов)). Хук запускает системный `python3`, поэтому нужны **Command Line Tools**: `xcode-select --install`. Без них хук молча ничего не передаёт, и агенты в острове не появляются.
- **Чтобы отвечать на вопросы Claude Code из острова** — Claude Code 2.1.85 или новее.
- **Для чата** — ключ провайдера (Claude, Gemini, OpenAI), локальная модель (Ollama, LM Studio) или установленный Claude Code, в который вы вошли по подписке. Нет Claude Code, вы не вошли или кончился лимит подписки — Luna скажет об этом; между подпиской и ключом она сама не переключается. Чата через Codex пока нет. Для «OK Luna» с Claude в роли мозга нужен ключ Anthropic API.
- **Сеть** — для установки, чата, «OK Luna» и подключённых сервисов. Других обращений в сеть и телеметрии нет.

## Установка

```sh
curl -fsSL https://raw.githubusercontent.com/stepaKaziatko/luna-assistant/main/install.sh | sh
```

Скрипт ([install.sh](../install.sh)) качает последний релиз, сверяет контрольную сумму и кладёт `Luna.app` в «Программы».

| Переменная | Что делает |
|---|---|
| `LUNA_VERSION=v1.0.0` | поставить конкретный релиз вместо последнего (ставятся и прежние, от v0.2.0) |
| `LUNA_INSTALL_DIR=~/Apps` | куда класть; по умолчанию `/Applications`, если он доступен на запись, иначе `~/Applications` |

### Что лежит в релизе

В каждом релизе два файла: `Luna-<версия>-macos-universal.zip` с `Luna.app` (arm64 и x86_64 в одном бандле) и `checksums.txt` с SHA-256. Ядра и сборок под другие системы нет.

### Вручную

Скачайте `Luna-<версия>-macos-universal.zip` со [страницы релиза](https://github.com/stepaKaziatko/luna-assistant/releases/latest), распакуйте и перенесите `Luna.app` в «Программы».

Сборка подписана ad-hoc и не нотаризована Apple, поэтому скачанную браузером копию macOS с первого раза не откроет. Откройте её способом Apple: попробуйте запустить Luna, затем зайдите в Системные настройки → Конфиденциальность и безопасность и нажмите «Всё равно открыть» рядом с сообщением о Luna. Это нужно один раз.

Скрипт установки снимает карантин с поставленного приложения сам, поэтому после него этот шаг не нужен.

### Обновление

Luna обновляется той же командой установки; встроенной проверки обновлений в приложении нет. Запущенную Luna скрипт закроет перед заменой — после этого запустите её снова. После обновления macOS может заново спросить разрешения.

Версия 1.0.0 — другое приложение, а не обновление 0.7.x: задачи, историю и настройки прежних версий она не переносит и не удаляет, прежние хоткеи 0.x не работают. Установка 1.0.0 заменяет `Luna.app` в «Программах».

## Первый запуск

```sh
open /Applications/Luna.app
```

У верхнего края экрана появится остров — в вырезе MacBook или полоской по центру на мониторе без выреза; в строке меню — значок Luna с меню: «Демо-режим», «Открыть Luna», «Итоги недели», «Настройки…», «Выход». Значка в Dock у Luna нет. Чтобы Luna запускалась сама, включите «Запускать при старте Mac» в Настройки → Основные.

`⌃⌥S` открывает страницу «Агенты». Пока агенты не подключены, на ней подсказка, как это сделать.

## Подключение агентов

Агенты появляются в острове только после установки хуков: страница «Агенты» строится из событий, которые присылает хук. Хуки ставятся вручную, по одному CLI:

1. Настройки → Агенты → блок нужного CLI → «Установить хуки» (у OpenCode, Amp и Hermes — «Установить плагин»).
2. Luna показывает, что именно запишет, — просмотрите и нажмите «Подтвердить и записать». Без подтверждения файл не меняется.
3. Начните новую сессию агента (Gemini CLI, Copilot CLI, OpenCode, Amp, Muse Code, Antigravity — перезапустите). Codex сначала попросит подтвердить хуки у себя: откройте Codex и выполните `/hooks`.

Там же кнопка «Удалить» убирает хуки Luna из настроек CLI. Перед записью существующего файла Luna кладёт рядом копию `<имя файла>.bak-<дата>`.

| CLI | Что меняет Luna |
|---|---|
| Claude Code | `~/.claude/settings.json` |
| Codex | `~/.codex/hooks.json` |
| Gemini CLI | `~/.gemini/settings.json` |
| Antigravity | `~/.gemini/config/hooks.json` |
| GitHub Copilot CLI | `~/.copilot/hooks/luna.json` |
| Muse Code | `~/.config/muse/settings.json` |
| OpenCode | `~/.config/opencode/plugins/luna.js` |
| Amp | `~/.config/amp/plugins/luna.ts` |
| Hermes | `~/.hermes/plugins/luna`; запросы подтверждения в острове — по отдельному переключателю, он меняет `~/.hermes/config.yaml` |

Сам хук — `luna-hook` и `luna-hook.py` в `~/Library/Application Support/Luna`; Luna кладёт их туда сама при запуске.

Ещё два необязательных пункта в Настройки → Агенты:

- **Вопросы и разрешения терминальных сессий в острове** — переключатель «Answer questions and permissions from terminal sessions in the notch». Выключен — сессии в Terminal, iTerm, Warp видны в острове, но спрашивают в терминале. Включён — сначала спрашивает остров, а терминал ждёт ответа до 2 минут.
- **Лимиты плана Claude в шапке** — блок «Использование плана» → «Установить ретранслятор». Добавляет строку состояния в `~/.claude/settings.json` (если своя строка состояния уже есть, она продолжает работать) и тоже показывает изменения перед записью; убирается кнопкой «Удалить ретранслятор». Только для планов Pro и Max.

## Проекты

Проект — папка на вашем Mac, обычно с `CLAUDE.md` или `AGENTS.md`. Список — в Настройки → Проекты:

- **«Добавить папку…»** — выберите папку. Та же папка второй раз не добавляется, имя можно поменять прямо в списке.
- **«Найти проекты Claude Code и Codex»** — по клику Luna читает только пути проектов из `~/.claude.json` и `~/.codex/config.toml` и показывает те, что ещё не добавлены, с галочками. Остальное в этих файлах (разрешения, MCP, история) Luna не читает и не хранит, и сами файлы не меняет. Домашняя папка целиком, служебные папки Luna и несуществующие пути не предлагаются.
- **«Убрать»** — проект уходит из списка, папка и её файлы остаются. Удалили или переименовали папку — проект помечен «Папка не найдена»; если macOS не дала Luna доступ к папке (Документы, Рабочий стол, iCloud), — «Нет доступа».

**Проект на странице вопроса.** Рядом с моделью, когда источник — Claude Code по подписке, есть выбор проекта; по умолчанию «Без проекта». С проектом запрос уходит не в чат, а агенту в папке проекта — см. [Агент в проекте](#агент-в-проекте). Выбор запоминается; если проект убрали или папка пропала, Luna вернётся к «Без проекта». «Без проекта» — чат, как раньше: служебная папка, только поиск в сети, без доступа к вашим файлам. Для ключа API и локальных моделей проект не выбирается.

**Проект у агента.** На странице агента вместо имени папки — «Проект: <имя>», если агент работает в привязанной папке или внутри неё. На странице «Агенты» переключатель «По проектам» собирает плитки в группы с именем проекта; сессии вне списка — в группе «Другие». Ждущий вас агент по-прежнему наверху. Стрелки идут по плиткам в порядке на экране: ← и → — по порядку, из конца группы в начало следующей; ↑ и ↓ — на ряд выше или ниже, в том числе в соседнюю группу.

## Агент в проекте

Задачу можно отдать агенту прямо со страницы вопроса: Luna сама запустит Claude Code в папке проекта, в фоне, по вашей подписке. Страница вопроса — не сама сессия агента, а точка входа в неё.

1. Источник — Claude Code по подписке. Выберите проект рядом с моделью.
2. Напишите задачу («создай файл hello.txt со строкой hi») и отправьте — Enter или стрелка.
3. Поле очищается, и сразу открывается страница нового агента. На «Агентах» у него плитка с приложением «Luna (в фоне)».

Это обычная сессия Claude Code в папке проекта: с `CLAUDE.md`, `.claude/settings.json` и хуками проекта и со всеми инструментами — правками файлов, командами, MCP. Luna не ограничивает его инструменты и не дописывает ему свой промпт; модель — та, что выбрана рядом с проектом.

**Разрешения.** Что агенту можно без вопроса, решают ваши настройки Claude Code и проекта (`permissions.allow`, `defaultMode`) — как в терминале. Остальное агент спрашивает: в острове появляется карточка с командой и кнопками Allow / Deny / Always, тот же запрос — на странице агента. Ничего не выполняется без вашего клика. Не ответили почти 2 минуты — запрос снимается с пометкой «Запрос истёк — агенту отказано»: агент получает отказ и заканчивает ход; продолжите разговор, чтобы он попробовал снова.

**Страница агента.** Пока агент работает — его шаги; закончил ход — ответ целиком (его можно выделить и скопировать). Ниже — поле «Продолжить…»: следующий ход той же сессии в той же папке; пока ход идёт, поле неактивно, а рядом кнопка «Остановить». Остановленный агент помечен «Остановлен» — разговор можно продолжить. «Перейти к агенту» у фонового агента нет — окна у него нет; «Открыть в…» переносит разговор в VS Code или Claude Desktop сразу, без ожидания: между ходами сессия уже закрыта.

**Каждая отправка со страницы вопроса — новый агент.** Продолжить прежнего можно только с его страницы. Чат из истории, открытый с проектом, при отправке тоже начинает нового агента в этом проекте.

**Вопросы.** В фоне Claude Code не задаёт вопросов карточкой: если агенту нужно уточнение, он напишет его в ответе — ответьте в «Продолжить…».

**Выход из Luna.** Агенты останавливаются. Если хоть один посреди хода, Luna спросит «Агенты работают (N). Остановить и выйти?». Плитки фоновых агентов живут до перезапуска Luna, в историю чатов запуски не пишутся. Разговор остаётся в Claude Code: `claude --resume` в папке проекта.

Если агент не запускается:

- **«Подключите Claude Code в Настройки → Агенты»** — без хуков Luna не видит агента, а его запросы разрешений отклонялись бы сразу. Кнопка в заметке открывает настройки.
- **Claude Code не найден или не вошёл** — установите CLI и войдите (`claude auth login`). Luna сама на ключ API не переключается.
- **Папка проекта не найдена или нет доступа** — проверьте папку в Настройки → Проекты; доступ к Документам, Рабочему столу и iCloud даётся в Системных настройках.
- Лимит подписки, нет сети, `claude` упал — ошибка на странице агента, плитка красная; «Продолжить…» остаётся доступным.

Сторожа тишины у агента нет: долгая сборка или команда идёт, сколько нужно. Новых разрешений macOS не нужно. Агент — только Claude Code и только в версии с GitHub; в версии из App Store его нет.

## Открыть сессию в другом приложении

Сессию Claude Code, которую видно на странице агента, можно продолжить не там, где она идёт: например, начатую в терминале — во вкладке Claude Code в VS Code или в Claude Desktop. Иконка «Открыть в…» (стрелка из окна) стоит рядом с «Перейти к агенту».

1. Дождитесь, пока агент закончит ход: пока он работает или ждёт вашего ответа, пункты меню неактивны.
2. Нажмите «Открыть в…» и выберите приложение:
   - **VS Code** — Luna откроет папку проекта в VS Code и в ней вкладку Claude Code с этим разговором;
   - **Claude Desktop** — разговор откроется в Claude Desktop (нужна подписка и вход в аккаунт);
   - **Скопировать команду для терминала** — в буфер обмена попадёт `cd '<папка проекта>' && claude --resume <id>`: вставьте её в любой терминал и нажмите Enter.
3. На странице появится «Закройте сессию в Terminal (`/exit`) — Luna откроет её в VS Code». Закройте сессию там, где она идёт: `/exit` в терминале или закройте вкладку Claude Code в VS Code. Как только сессия закроется, Luna откроет её в выбранном приложении, а остров свернётся.

Почему не сразу: один разговор нельзя вести в двух местах одновременно — сообщения перепутаются. Поэтому Luna открывает сессию только после того, как прежнее место её отпустило.

Перенос снимается:

- кнопкой «Отменить» на странице агента;
- сам, если вы продолжили работу в прежнем месте (новый вопрос агенту) — «Сессия продолжила работу — перенос отменён»;
- сам через 5 минут, если сессия так и не закрылась, — «Сессия не закрылась — перенос отменён». Так бывает, если закрыть окно терминала целиком: тогда откройте разговор вручную — `/resume` в Claude Desktop или история сессий в VS Code;
- при выходе из Luna.

Ждёт один перенос: новый выбор заменяет прежний.

Если чего-то нет:

- **Иконки нет** — у агента не Claude Code, Luna не знает id его сессии, или сессия идёт в самом Claude Desktop.
- **Нет пункта VS Code или Claude Desktop** — приложение не установлено, или сессия уже идёт в нём (туда ведёт «Перейти к агенту»).
- **VS Code «нет расширения Claude Code»** — поставьте расширение Claude Code в VS Code.
- **«Папка проекта не найдена»** — папки сессии нет на диске; Claude Desktop и без неё доступен.
- Команда в терминале для сессии, которая ещё открыта в другом месте, продолжит разговор копией — `claude` скажет об этом.

Новых разрешений macOS не нужно: Luna только открывает папку и ссылку в выбранном приложении и кладёт команду в буфер обмена. Сама она ничего не запускает и ничего не печатает в чужие окна. В версии из App Store этой кнопки нет.

## История чатов

Luna запоминает ваши чаты: на странице вопроса слева от выбора проекта и модели — иконка истории и «+».

- **История** (иконка с часами) — над островом открывается список прошлых чатов, новые сверху: заголовок по первому вопросу, когда был последний ответ, чем отвечено, проект. Приложение, в котором вы работаете, остаётся активным; `⎋` или клик мимо закрывают список. Выберите чат — его переписка вернётся на страницу, и можно продолжать. По подписке разговор продолжается в той же сессии Claude Code, по ключу API модель получает прежнюю переписку текстом. Чат, который шёл в проекте, открывается для чтения: отправка с проектом запускает нового агента. Источник Luna сама не меняет: если чат шёл через Claude Code, а сейчас выбран ключ (или наоборот), над полем ввода появится пометка и кнопка «Продолжить через …» — источник сменится только по клику. Если проект чата убрали или его папка пропала, вопрос уйдёт «Без проекта», в новый чат.
- **«+»** — новый чат, то же, что `⌘K`. Открытый чат остаётся в истории.
- **Корзина** на строке списка (появляется при наведении) удаляет чат из истории. Удалили открытый — страница становится новым чатом. Разговоры, которые Claude Code хранит у себя в `~/.claude/projects`, Luna не трогает.
- Если Claude Code уже не может продолжить прежнюю сессию (её транскрипт удалён или вы вошли в другой аккаунт), Luna отметит это в чате и сама один раз задаст тот же вопрос в новой сессии — без прежнего контекста.

Хранятся 100 последних чатов, старые удаляются сами. В Настройки → Чат → «История чатов» — переключатель «Хранить историю чатов» (включён по умолчанию; выключение не стирает уже записанное) и «Очистить историю…». История лежит на этом Mac без шифрования (права только у вашей учётной записи); прикреплённые файлы в неё не попадают — только их имена. Поиска по истории пока нет.

## Хоткеи

Глобальные сочетания работают из любого приложения; посмотреть и поменять их можно в Настройки → Горячие клавиши.

| Действие | Хоткей |
|---|---|
| Открыть чат | `⌃⌥Space` |
| Открыть «Агенты» (повторное нажатие закрывает остров) | `⌃⌥S` |
| Открыть «Активные вкладки» (повторное нажатие закрывает остров) | `⌃⌥P` |
| К ожидающему запросу агента | `⌃⌥A` |
| В терминал агента | `⌃⌥T` |
| Прикрепить переднее окно как контекст | `⌃⌥W` |
| Следующая / предыдущая вкладка | `⌃⌥]` / `⌃⌥[` |
| Включить / выключить звук | `⌃⌥M` |
| Персонаж на рабочий стол и обратно | `⌃⌥D` |
| Гардероб | `⌃⌥G` |
| Свернуть раскрытую шторку (пока шторка свёрнута, сочетание свободно для других приложений) | `⌘⎋` |

Ещё два сочетания по умолчанию выключены и включаются в настройках: `⌘⇧N` — открыть и закрыть остров, `⌃⌥V` — говорить с Luna без слова-активатора.

### Клавиши острова

После хоткея страницы (или клика по острову) клавиатура у острова, а приложение, в котором вы работали, остаётся активным. `?` в острове показывает клавиши текущей страницы.

| Где | Клавиши | Что делают |
|---|---|---|
| Любая страница | `⎋` | закрыть остров (если он не закреплён) |
| Любая страница | `?` | показать / скрыть клавиши страницы |
| «Агенты» | стрелки | выбрать агента |
| «Агенты» | `↩` | открыть страницу выбранного агента |
| «Агенты», страница агента | `⌘↩` | перейти к окну агента |
| Страница агента | `⌫` | назад к списку агентов |
| «Активные вкладки», GitHub | `⌫` | назад к «Агентам» |
| «Активные вкладки» | `←` / `→`, `↑` / `↓`, `↩` | вкладка, элемент списка, открыть выбранное |
| GitHub | стрелки, `↩` | выбрать pull request или репозиторий, открыть на GitHub |
| Запрос разрешения | `←` / `→`, затем `↩` | выбрать «Запретить», «Разрешить» или «Всегда», затем отправить |
| Вопрос агента | стрелки или `1–4`, затем `↩` | выбрать вариант, затем ответить |
| Вопрос с несколькими ответами | `Space` | отметить / снять вариант |

Ответ на запрос и вопрос — всегда в два шага: стрелка или цифра только выбирают, отправляет `↩`. Работают и прежние клавиши острова: `⌘←` / `⌘→` и `⌘1–9` — вкладки, `⌘↑` / `⌘↓` — элементы списка, `⌘O` — открыть выбранное, `⌘E` — открыть и закрыть diff в «Активных вкладках», `⌘,` — настройки, `⌘P` — закрепить остров; в чате `⌘↩` отправляет сообщение, `⌘K` начинает новый разговор (как кнопка «+» на странице вопроса).

## Разрешения macOS

Luna просит их по мере надобности, а не при старте, и без них работает в урезанном виде. После обновления macOS может спросить разрешения заново.

| Разрешение | Зачем |
|---|---|
| Автоматизация | перейти к вкладке агента в Terminal и iTerm2 (спрашивается при первом нажатии «Перейти к агенту»), прочитать адрес открытой вкладки браузера (Safari, Chrome, Arc, Firefox, Edge), когда его окно прикрепляют как контекст, управлять Музыкой и Spotify, отправить письмо через Mail |
| Универсальный доступ | заголовок активного окна, когда его прикрепляют как контекст |
| Микрофон и распознавание речи | диктовка в чат и «OK Luna» |
| Контакты | адрес получателя, когда письмо просят голосом |
| Доступ к папкам «Документы», «Рабочий стол», «Загрузки», iCloud Drive | проект в такой папке: значки `CLAUDE.md` / `AGENTS.md` в списке проектов и вопрос в этом проекте |

## Проверка файлов

К каждому релизу приложен `checksums.txt` с SHA-256 всех файлов:

```sh
shasum -a 256 -c checksums.txt --ignore-missing
```

Релиз публикуется только после проверки в workflow [Release](../.github/workflows/release.yml): на macOS 15 и macOS 26 собранный архив ставится скриптом установки, сверяются подпись и архитектуры, приложение запускается и завершается по сигналу. После публикации тот же прогон проверяет, что архив скачивается и сумма сходится.

## Удаление и данные

1. Снимите хуки: Настройки → Агенты → «Удалить» у каждого CLI, где они стоят, и «Удалить ретранслятор», если ставили его. Иначе в настройках CLI останется команда, которая вызывает уже несуществующий `luna-hook`.
2. Выключите «Запускать при старте Mac» в Настройки → Основные, если включали.
3. Выйдите из Luna (значок в строке меню → «Выход») и удалите `Luna.app` из «Программ».

Вместе с приложением данные не удаляются. Где они лежат — удалите сами то, что не нужно:

| Что | Где |
|---|---|
| Хук, сокет, итоги недели (`recap.json`), папка чата, свои звуки (там же — данные версий 0.x) | `~/Library/Application Support/Luna` |
| История чатов Luna | `~/Library/Application Support/Luna/ChatHistory`: `index.json` и по файлу на чат; стереть — Настройки → Чат → «Очистить историю…» или удалить папку |
| Журналы | `~/Library/Logs/Luna` |
| Настройки | `defaults`, домен `dev.luna.Luna` |
| Ключи сервисов и моделей | Связка ключей, служба `dev.luna.Luna` |
| Переписка чата через Claude Code | у самого Claude Code: `~/.claude/projects`, папка `…Luna-chat`; вопросы в проекте — в папке этого проекта там же |
| Список проектов и выбранный проект | настройки (`defaults`, ключи `chatProjects`, `chatProjectID`) |
| Хранить ли историю чатов | настройки (`defaults`, ключ `chatHistoryEnabled`) |
| Резервные копии настроек CLI | рядом с файлами из таблицы [Подключение агентов](#подключение-агентов), `*.bak-<дата>` |
