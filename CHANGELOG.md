# Что нового

Раздел версии уходит в заметки публичного релиза — пишите его для пользователя Luna, а не для разработчика. Ещё не выпущенные изменения копятся в разделе «Дальше»; при выпуске он получает номер версии.

## Дальше

- Luna стала другим приложением: теперь она живёт в вырезе MacBook (на мониторе без выреза — в полоске у верхнего края) и показывает сессии ваших ИИ-агентов — Claude Code, Codex, Gemini CLI, Cursor, Copilot CLI, OpenCode, Amp, Hermes и других: у каждой своя «таблетка» с аватаром, что агент читает, правит и запускает, правки файлов с `+N −M` и полный diff по клику. Прежние панели вопросов и задач, ядро и захват контекста ушли; в основе — открытый проект coucou, перенесённый под именем Luna.
- Новая страница острова «Агенты» (вторая вкладка в шапке): по плитке на каждую сессию агента — Claude Code, Codex, Gemini CLI, Cursor и других. На плитке аватар в цвете агента, проект, приложение, где идёт сессия (VS Code, терминал…), значки последних шагов и статус. Тот, кто ждёт вашего разрешения или ответа, стоит первым и горит оранжевым; закончивший ход — зелёным, пока вы не открыли страницу; ошибка — красным. Две сессии под одним VS Code — две плитки. Страница обновляется сама, а пока она не на экране, ничего не рисует; нет агентов — подсказка, как их подключить. Клик по плитке открывает страницу этого агента.
- Страница агента: клик по плитке показывает одну сессию подробно — проект, агента, приложение, где она идёт, и последние 20 шагов. Если агент ждёт вас, на этой же странице его вопрос с вариантами ответа или запрос разрешения с кнопками Allow / Deny / Always: ответили здесь — запрос исчез с карточки, и наоборот; ответ не уходит дважды, а порядок запросов прежний — отвечать можно тому, кто первый в очереди, остальные видны с номером («в очереди №2 из 3»). Кнопка «Перейти к агенту» открывает окно, где идёт сессия: в VS Code и родственных редакторах — папку проекта и вкладку Claude Code, в Terminal и iTerm2 — именно ту вкладку (macOS один раз спросит разрешение «Автоматизация» на нажатии кнопки), в других терминалах — само приложение, а если неизвестно, где запущен агент, — папку проекта в Finder. После перехода остров сворачивается.
- Запросы агента на разрешение приходят в остров с кнопками Allow / Deny / Always, вопросы с вариантами ответа — прямо в остров; одной командой можно перейти к терминалу сессии. Ничего не разрешается без вашего клика.
- Чат с Claude, Gemini, OpenAI или локальной моделью по своему ключу, диктовка, лимиты плана Claude и Codex в шапке; интеграции с GitHub, Vercel, Stripe, Resend, n8n, Notion, Cal.com, Apple Music, Spotify, Apple Mail и курсами криптовалют; файл можно бросить на остров; еженедельный отчёт по понедельникам.
- В острове — маленький собственный персонаж Luna: дышит, моргает, следит за курсором, радуется законченной сессии; его можно вытащить на рабочий стол и одеть. Голосовое управление «OK Luna» — распознавание речи на Mac, Claude в роли мозга.
- Подключение агентов: Luna предлагает добавить свой хук в настройки Claude Code и других CLI и показывает, что изменит, — файл без подтверждения не трогается. Интерфейс на десяти языках, ключи — в Keychain, без телеметрии. Нужна macOS 15 или новее.

## 0.7.0

- Шторка на MacBook с вырезом стала продолжением выреза: чёрная фигура чуть шире камеры, её края плавно уходят в строку меню — без шва и светлой каймы, и сразу видно, что Luna работает. Когда агент ждёт вас, закончил ход или готов ответ, из выреза вырастают крылья: слева Luna, справа счётчики и аватары сессий — под камерой ничего не прячется. На мониторе без выреза у верхнего края по центру — чёрный псевдо-остров той же формы высотой со строку меню.
- Панели вырастают из выреза той же чёрной фигурой и втягиваются обратно: вопрос по `⌥ Space`, список задач, ответ, агенты и блок под курсором. Всё содержимое — ниже камеры, тень мягко гаснет к строке меню. На мониторе без выреза панель растёт из псевдо-острова у верхнего края того монитора, где курсор.
- Шторка в строке меню не мешает ей: пункты меню и значки рядом с островом нажимаются, а клик и наведение срабатывают только на самой чёрной фигуре, вместе с её краями. Курсор, который просто проходит по строке меню мимо острова, блок с агентами не открывает. Над приложением, развёрнутым на весь экран, на MacBook с вырезом остров стоит в чёрной полосе камеры без крыльев и не закрывает видео; панели по хоткею и клику открываются как обычно, а вышли из полноэкранного режима — крылья вырастают снова. На мониторе без выреза псевдо-остров остаётся у верхнего края; кому он мешает — «Показывать шторку» → «В фоне».
- Если открыть панель и сразу закрыть — дважды быстро нажать `⌥ Space` или нажать `Esc` сразу после хоткея, — шторка возвращается к обычному виду, а не остаётся чёрным блоком размером с панель.

## 0.6.0

- В панели ввода внизу видно, на какой модели уйдёт вопрос: «Claude Code · Модель CLI». Клик по надписи открывает список моделей (Opus, Sonnet, Haiku): выберите — и вопрос уйдёт на ней. Выбор запоминается между запусками. В карточке ответа подписано, на какой модели он получен: «Claude Code · Sonnet 4.6 · 12 с». Если модели нет у вашего аккаунта, Claude Code отвечает ошибкой, а выбор можно сразу поменять. Без выбора всё работает как раньше.
- Список моделей и модель по умолчанию настраиваются: значок луны в строке меню → «Настройки…» → «Основные» → «Модели». Добавьте свою модель — алиасом (`opus`) или полным идентификатором (`claude-opus-4-8[1m]`), уберите ненужные, выберите, какая из них идёт по умолчанию: панель ввода предложит её, пока вы не выбрали другую. «Модель CLI» значит, что Luna модель не указывает: работает `LUNA_CLAUDE_MODEL`, если она задана, иначе модель из настроек Claude Code; выбранная в панели «Модель CLI» тоже запоминается. Некорректная строка подсвечивается и в список не попадает; убрали модель, которую вы выбирали или поставили по умолчанию, — вместо неё предлагается «Модель CLI». Сменили модель по умолчанию — панель сразу предлагает новую.
- Диалог можно продолжить на другой модели: в карточке ответа по `Tab` встаньте в поле «Продолжить диалог…», откройте список рядом («Claude Code · Sonnet 4.6») и выберите другую модель — следующий ответ придёт от неё, а диалог останется тем же. Без выбора уточнение идёт на той модели, на которой остановился диалог. В окне «Открыть полностью» в шапке видно, на какой модели последний ответ.
- В карточке и в окне сессии агента, запущенного не Luna (VS Code, Cursor, терминал), видно, на какой модели она работает: «Opus 5.5». Если в сессии сменить модель командой `/model`, подпись обновится после следующего ответа агента. Модель чужой сессии из Luna менять нельзя — только смотреть.

## 0.5.0

- Из Luna всегда можно выйти, даже если значка луны не видно (вырез на экране, менеджер значков): правый клик по шторке открывает то же меню, что и значок, в окне настроек есть `⌘Q` и кнопка «Выйти из Luna». Если открыть Luna.app, пока она уже работает (Spotlight, Finder), откроется окно настроек. Идущие задачи при выходе по-прежнему помечаются ошибкой «Luna была закрыта до завершения задачи».
- Новая настройка «Показывать шторку» («Основные» → «Шторка»): «Всегда» (как раньше) или «В фоне». В фоне Luna работает как обычно — хоткеи, значок в строке меню, наблюдение за агентами, — а шторка на экране не висит: она плавно появляется, когда агент ждёт вас или закончил ход, готов ответ Luna или задача завершилась ошибкой, и через несколько секунд уходит. Курсор над шторкой или открытая панель её удерживают; закрыли панель — шторка уходит сразу. Наведение на край экрана в фоне ничего не раскрывает. Скрытая шторка не тратит процессор, а приложение, в котором вы работаете, остаётся активным.

## 0.4.0

- Luna видит агентов, которых запустили не через неё: сессии Claude Code в VS Code, Cursor и терминалах. `⌃ ⌥ Space` или клик по шторке — сетка плиток: у каждой сессии аватар, проект и превью работы — значки последних шагов и пара слов о том, чем агент занят или чего ждёт. Настраивать ничего не нужно.
- В сессию можно провалиться в три шага. `↩` на плитке — карточка: о чём сессия и живая лента шагов. `␣` в карточке — отдельное окно с подробной лентой: запросы, ответы агента целиком и вызовы инструментов; окно не забирает фокус и обновляется само. `↩` в карточке (или `⌘↩` в сетке, или значок приложения на плитке) — сам чат: окно редактора с вкладкой именно этой сессии или вкладка терминала.
- Шторка стала короче: вместо фразы — значки со счётчиками (ждут вас, готово, в работе, ошибки) и аватары сессий. Фразу можно вернуть в настройках.
- Остров растёт в ширину, а не вниз: карточки шире и ниже прежних, сессии и диалоги идут рядами плиток.
- У Luna и у каждой сессии появились аватары — маленькие луны: моргают, озираются за работой, подпрыгивают, когда зовут вас, спят, когда свободны. У проекта свой цвет.
- Панели больше не появляются рывком: pill плавно перетекает в карточку и обратно. Системная настройка «Уменьшение движения» учитывается.
- Наведите курсор на шторку у верхнего края экрана — из неё выезжает блок с плитками агентов и последними диалогами. Клик по плитке открывает карточку, значок приложения на ней ведёт к окну сессии; курсор ушёл — блок убрался. Клавиатуру блок не забирает: приложение, в котором вы работаете, остаётся активным.
- Появились настройки: значок луны в строке меню → «Настройки…» или шестерёнка в блоке под курсором. В них — цвет и аксессуар Luna (кольцо, колпак, очки), звуки и сочетания клавиш; раскрытие по наведению и анимацию аватаров можно выключить.
- Luna бережёт процессор: свёрнутая шторка оживает ненадолго — когда что-то произошло, когда рядом курсор и изредка сама, — а не анимируется без остановки; при погашенном экране анимации стоят. Журналы агентов дочитываются, а не перечитываются.
- Luna сообщает звуком, когда агент ждёт вас или закончил ход, когда готов её ответ и когда задача завершилась ошибкой. Для каждого события выбирается свой системный звук или тишина, громкость общая.

## 0.3.0

- Список задач сохраняется между запусками: после перезапуска Luna прежние запросы и ответы на месте. Задача, которую прервал выход из Luna, помечена ошибкой «Luna была закрыта до завершения задачи».
- Диалог можно продолжить прямо из карточки ответа: `Tab`, уточнение, `↩` — Claude Code отвечает с учётом прежнего разговора, а приложение, в котором вы работаете, остаётся активным. Карточка показывает диалог целиком, в списке задач он занимает одну строку. Продолжить можно и вчерашний диалог из истории.
- Уточнение работает и тогда, когда Claude Code уже не помнит разговор: Luna сама отправляет ему прежнюю переписку заново.
- Поиск по истории: в списке задач сразу можно печатать — список сужается до диалогов, где слова есть в запросе или ответе, включая давние. `⌘⌫` удаляет выбранный диалог, кнопка «Очистить историю» внизу списка — все завершённые. Удаление необратимо; разговоры в истории самого Claude Code остаются.
- «Открыть полностью» в карточке ответа: диалог открывается в отдельном окне, которое можно растянуть, подвинуть и оставить рядом с работой. Окно не забирает фокус у вашего приложения, обновляется вместе с диалогом, выделенный текст копируется `⌘C`, размер запоминается; `esc` закрывает окно.
