# Что нового

Раздел версии уходит в заметки публичного релиза — пишите его для пользователя Luna, а не для разработчика. Ещё не выпущенные изменения копятся в разделе «Дальше»; при выпуске он получает номер версии.

## Дальше

- Список задач сохраняется между запусками: после перезапуска Luna прежние запросы и ответы на месте. Задача, которую прервал выход из Luna, помечена ошибкой «Luna была закрыта до завершения задачи».
- Диалог можно продолжить прямо из карточки ответа: `Tab`, уточнение, `↩` — Claude Code отвечает с учётом прежнего разговора, а приложение, в котором вы работаете, остаётся активным. Карточка показывает диалог целиком, в списке задач он занимает одну строку. Продолжить можно и вчерашний диалог из истории.
- Уточнение работает и тогда, когда Claude Code уже не помнит разговор: Luna сама отправляет ему прежнюю переписку заново.
- Поиск по истории: в списке задач сразу можно печатать — список сужается до диалогов, где слова есть в запросе или ответе, включая давние. `⌘⌫` удаляет выбранный диалог, кнопка «Очистить историю» внизу списка — все завершённые. Удаление необратимо; разговоры в истории самого Claude Code остаются.
- «Открыть полностью» в карточке ответа: диалог открывается в отдельном окне, которое можно растянуть, подвинуть и оставить рядом с работой. Окно не забирает фокус у вашего приложения, обновляется вместе с диалогом, выделенный текст копируется `⌘C`, размер запоминается; `esc` закрывает окно.

## 0.2.0

- Luna видит, над чем вы работаете: приложение, адрес и заголовок страницы в Safari и браузерах на Chromium, выделенный текст. Контекст показан под полем ввода, лишнее убирается перед отправкой.
- Список задач по `⌥ ⌘ Space`: статус, прогресс, отмена, переход к результату.
- Приложение собирается под Apple Silicon и Intel.

## 0.1.0

- Глобальный хоткей `⌥ Space`, панель ввода, фоновые задачи через Claude Code и карточка результата — без кражи фокуса.
