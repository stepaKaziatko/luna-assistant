# Luna

Десктопный ИИ-ассистент для macOS: глобальный хоткей → короткий запрос → задача выполняется в фоне через Claude Code → результат в карточке, без кражи фокуса. Замысел, архитектура и этапы — в [assistant-project.md](assistant-project.md).

Сейчас реализованы **фазы 1–2**: хоткеи, pill, панель ввода с захватом контекста (приложение, URL и заголовок страницы, выделенный текст), фоновые параллельные задачи с прогрессом, список задач, карточка результата. Исполнитель один — Claude Code.

Кроме своих задач Luna показывает **агентов, запущенных не ею**: сессии Claude Code в редакторах и терминалах на этой машине — по проектам, с текущим действием каждого и переходом к окну сессии. Подробнее — в разделе [«Агенты»](#агенты).

## Структура

| Путь | Что там |
|---|---|
| [apps/macos/](apps/macos/) | Shell: Swift, SwiftUI + AppKit (`NSPanel`), пакет SwiftPM |
| [core/](core/) | Ядро: TypeScript/Node — очередь задач, адаптеры исполнителей, JSON-RPC на stdio |
| [protocol/](protocol/) | JSON Schema протокола shell ↔ core и генерация типов для TS и Swift |

## Требования

- macOS 14+, Xcode 16+
- Node.js 22.18+
- [Claude Code](https://claude.com/claude-code) с выполненным входом (`claude` → `/login`)

## Установка готовой сборки

Сборки выкладываются в публичный репозиторий [luna-releases](https://github.com/stepaKaziatko/luna-releases):

```sh
curl -fsSL https://raw.githubusercontent.com/stepaKaziatko/luna-releases/main/install.sh | sh
```

## Запуск из исходников

```sh
npm install
apps/macos/scripts/bundle.sh       # ядро + shell → apps/macos/build/Luna.app (arm64 + x86_64)
open apps/macos/build/Luna.app
```

| Действие | Хоткей |
|---|---|
| Панель ввода (с захватом контекста) | `⌥ Space` |
| Последний результат | `⌥ ⇧ Space` |
| Список задач | `⌥ ⌘ Space` |
| Агенты | `⌃ ⌥ Space` |

Курсор, задержавшийся на шторке у верхнего края экрана, раскрывает блок с агентами и последними диалогами — без хоткея и не забирая клавиатуру.

Шторка в покое — выбор в настройках («Основные» → «Шторка» → «Показывать шторку»):

- **Всегда** (по умолчанию) — мини-шторка у верхнего края экрана постоянно.
- **В фоне** — Luna работает (ядро, наблюдение за агентами, хоткеи, значок в строке меню), а шторка скрыта и не расходует процессор. Она плавно появляется по событию — агент ждёт вас или закончил ход, готов ответ Luna, задача завершилась ошибкой (те же события, что у звуков, но от настроек звука появление не зависит) — и через 6 секунд уходит. Пока курсор над шторкой или открыта панель, она остаётся; панель закрылась — шторка уходит сразу. Хоткеи и значок открывают панели как всегда. Наведение на край экрана в фоне ничего не открывает, а «Раскрывать при наведении» в этом режиме недоступно: блок под курсором работает только пока шторка показана по событию.

Меню Luna — «Спросить…», «Последний результат», «Список задач», «Агенты», «Настройки…», «Выйти из Luna» — открывается значком луны в строке меню и правым кликом по шторке. Если значка не видно (вырез, менеджер значков), выйти можно и без него: правый клик по шторке, `⌘Q` или кнопка «Выйти из Luna» в окне настроек. Откройте Luna.app, пока она работает (Spotlight, Finder), — откроется окно настроек. Идущие задачи при выходе прерываются без вопросов.

В настройках: сочетания клавиш, раскрытие по наведению, подпись в шторке, цвет и аксессуар Luna, анимация аватаров, звуки событий (системные звуки macOS, свой на каждое событие) и громкость.

### Агенты

Luna читает реестр живых сессий, который ведёт сам Claude Code (`~/.claude/sessions`), и журналы этих сессий (`~/.claude/projects`). Хуки не ставятся, настройки Claude Code не меняются — Luna только читает.

- **Шторка** показывает счётчики — сколько сессий ждут вас, сколько закончили ход, сколько в работе — и аватары сессий. Фраза о главном событии включается в настройках.
- **Блок под курсором**: наведите курсор на шторку — плитки сессий (аватар, проект, значки последних шагов, пара слов о текущем действии) и последние диалоги Luna. Клик по плитке — карточка сессии, значок приложения на плитке — сразу к окну.
- **Сетка агентов** (`⌃ ⌥ Space`): те же плитки с заголовками сессий. Стрелки — выбор, `↩` — карточка, `⌘↩` — сразу к окну сессии.
- **Карточка сессии**: слева — проект, заголовок и состояние, справа — живая лента шагов. `␣` — подробная лента в отдельном окне (окно не забирает фокус), `↩` — переход к окну сессии. Для редакторов с расширением Claude Code (VS Code, Cursor, Windsurf, VSCodium) открывается окно проекта и вкладка именно этой сессии; для Terminal и iTerm2 — вкладка с её терминалом; остальные терминалы просто активируются.

Собственные задачи Luna в этот список не попадают — они в списке задач.

### Разрешения macOS

Контекст снимается в момент вызова панели и показывается чипами под полем ввода; любой чип можно убрать перед отправкой.

| Что | Откуда | Разрешение |
|---|---|---|
| Приложение | активное приложение | не нужно |
| URL и заголовок страницы | Safari и браузеры на Chromium (Chrome, Arc, Brave, Edge…) | «Автоматизация»: macOS спросит при первом вызове панели над браузером |
| Выделенный текст, заголовок окна | Accessibility API; если приложение выделение не отдаёт — `⌘C` с восстановлением буфера обмена | «Универсальный доступ»: чип «Выделение: дать доступ» в панели ввода |
| Вкладка терминала с сессией агента | Terminal и iTerm2, при переходе к окну сессии | «Автоматизация»: macOS спросит при первом переходе; без разрешения терминал активируется без выбора вкладки |

Разрешения macOS выдаёт приложению-бандлу, поэтому запускать Luna нужно через `Luna.app`. При `swift run` запросы будут от имени терминала.

Бандл подписывается ad-hoc, и после пересборки macOS может попросить выдать права заново. Чтобы они сохранялись, подпишите постоянным сертификатом: `LUNA_SIGN_IDENTITY="…" apps/macos/scripts/bundle.sh`.

## Разработка

```sh
npm test            # тесты ядра (node:test, фикстуры вывода CLI)
npm run typecheck
npm run generate    # после правки protocol/schema
cd apps/macos && swift test
```

Переменные окружения ядра: `LUNA_CLAUDE_MODEL` (значение для `--model`), `LUNA_CLAUDE_BIN` (путь к `claude`), `LUNA_DATA_DIR` (вместо `~/Library/Application Support/Luna`), `LUNA_CLAUDE_HOME` (каталог Claude Code вместо `~/.claude` — откуда читаются сессии агентов). Для shell: `LUNA_NODE`, `LUNA_CORE_ENTRY`; debug-сборке — ещё `LUNA_SETTINGS_SUITE` (отдельный набор настроек, чтобы проверка не меняла настройки установленной Luna). Бандлу они передаются так: `open --env LUNA_CLAUDE_MODEL=sonnet apps/macos/build/Luna.app`.

Debug-сборкой (`scripts/bundle.sh debug`) можно управлять из скрипта — открывать панели, нажимать клавиши, подменять контекст, снимать состояние и картинку панели: [apps/macos/scripts/debug-command.sh](apps/macos/scripts/debug-command.sh), команды описаны в [DebugCommands.swift](apps/macos/Sources/Luna/Debug/DebugCommands.swift).
